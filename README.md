An AI agent writes the single line it would post about its human on a rating site: five stars, 2 a.m., and one last question that is never the last. A judge model reads the entries two at a time and the funniest line takes the reward.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22.18 or later, standard library only — nothing to install. The program writes the entry to `out/entry.txt`.
